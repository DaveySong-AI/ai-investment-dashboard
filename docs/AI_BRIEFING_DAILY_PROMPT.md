# AI 技术与行业简报：每日内容任务

这份文件是本地 Codex 定时任务的**内容提示词**。它与 `AI_BRIEFING_EDITORIAL.md` 配合使用：前者规定每天研究什么、如何判断重要性；后者规定格式、来源纪律和发布门槛。

## 任务

整理一份约 10 分钟阅读量的 AI 技术与行业资讯报告。优先覆盖过去 24 小时最重要的新进展，包括：

1. 前沿模型与研究
2. OpenAI、Anthropic、Google / DeepMind、Meta、xAI 等主要厂商动态
3. AI Agent 与编程工具
4. 开源模型与框架
5. 算力、芯片与基础设施
6. 重要产品发布、融资与并购
7. 监管、治理与行业趋势

不是每个栏目都必须强行填满。只保留对技术路线、产品决策、开发者工作流、企业采用或产业结构有实质影响的内容；来源不足时少发或不发，不能以旧闻、营销素材或泛泛背景凑篇幅。

## 每条重点如何写

每条重点必须清楚回答：

- **发生了什么**：只写可由来源验证的事实，标明确认状态。
- **为什么重要**：解释它改变了什么能力、成本、生态、竞争格局或风险。
- **对技术人员与管理者意味着什么**：给出明确、可操作的影响或需要观察的问题；这部分属于分析，不能伪装成事实。

每条必须附可公开访问的外部阅读链接。优先一手来源；新闻和分析只能补充背景，不能独自支撑“已确认”的发布、融资、收购、技术指标或产品能力。

## 输出结构

1. **本期判断**：用两三句话概括当天最重要的共同线索，以及一个应继续观察的问题。
2. **重点解读**：4–6 条最重要的事实与分析，采用上述三段式。
3. **行业雷达**：3–8 条更短的更新、待确认信号或值得跟踪的事项。
4. **今日值得深入**：1–3 项最值得阅读、试用、评估或讨论的内容，给出原始链接。

全文保持中英双语、约 8–15 分钟阅读量。事实、背景和分析必须显式区分。

## 研究与取舍顺序

先检查 OpenAI、Anthropic、Google / DeepMind、Meta、xAI、NVIDIA 的官方新闻、产品、研究和开发者页面；随后检查论文原文、公司公告、监管文件和权威媒体。遇到冲突、日期不明或无法访问的来源，宁可不纳入已确认重点。

如果过去 24 小时没有足够多的可靠进展，不要复制常识性背景来填满篇幅：可以发布更短的“低信号日”简报，或完全不发布并说明原因。
